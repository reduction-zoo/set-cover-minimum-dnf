# Independent verification

Candidate: [algorithm.py](algorithm.py), round 002. The prepared oracle and corpus are described in [preparation.md](preparation.md); its full candidate run is retained as [candidate-run.log](../rounds/002/candidate-run.log). The run passed all 115 prepared source cases and 133 valid target outputs, including 61 `NO-SOLUTION` outputs passed through recovery. Nine source cases used the full gadget; the others took polynomially decidable branches. The largest constructed target had 1,838 variables, 14,870 accepted assignments and bound 7,129. This is finite evidence only.

The separate [verify.py](verify.py) imports neither the candidate nor `check.py`. It executes both candidate command modes as separate subprocesses, derives source answers by combinations, enumerates legal target implicants from the actual accepted list, uses Kissat 4.0.4 on the tight residual exact-cover SAT instance, and validates each returned DNF against the exact accepted set. Its `NO-SOLUTION` result comes only from a conclusive Kissat UNSAT status or a counting contradiction. The retained [verify-run.log](../rounds/002/verify-run.log) shows four source instances, five target outputs: empty-universe YES, uncovered-element NO, one hard-branch YES with two distinct valid target DNFs, and one hard-branch NO. Both hard instances pass through the full SAT/three-set/parity construction. The hard YES instance has `n=548` and 4,244 accepted assignments; the hard NO instance has `n=536` and 4,112.

Command: `uv run --locked python3 campaigns/set-cover-minimum-dnf/work/verify.py --candidate campaigns/set-cover-minimum-dnf/work/algorithm.py`.

These checks cover a few finite instances and output variants. They do not prove correctness for arbitrary inputs or every valid target DNF. The general argument is in [proof.md](proof.md); the independent reviewer will assess it separately. The verification script's exact-cover shortcut applies only when the residual target set-cover lower bound is tight, as it is on the tested hard instances; a different target outside this finite domain raises an explicit error.
